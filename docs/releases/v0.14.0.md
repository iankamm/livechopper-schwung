## Loop

- **Loop now plays like Move's:** a pad plays from the slice's start, then
  repeats the part from Offset for Loop Len, with a 9 ms crossfade at each
  repeat instead of a dip in level. Loop Len follows Transpose, as on Move.
- **A loop that runs past the slice's end plays silence there**, as Move's
  does, so a high Offset with a long Loop Len has a gap in each repeat.
- Passes held-out tests against Move's own output, checked on the
  device and by ear.
