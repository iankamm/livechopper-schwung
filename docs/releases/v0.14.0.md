## Loop

- **Loop approximates Move's:** a pad plays from the slice's start, then
  repeats the part from Offset for Loop Len, smoothly instead of with a
  dip in level at each repeat. Loop Len follows Transpose, as on Move.
- **A loop that runs past the slice's end plays silence there**, as Move's
  does, so a high Offset with a long Loop Len has a gap in each repeat.
- Checked against Move's own output, on the device and by ear.
